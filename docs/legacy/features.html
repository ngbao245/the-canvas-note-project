Trang này là gì

bibo hiện có 1 tool chính là Canvas (bảng trắng kiểu Milanote: đặt note, board con lên mặt phẳng vô hạn). Xung quanh có các phần dùng chung cho cả app: Cài đặt, Phím tắt, Đa ngôn ngữ, Giao diện sáng / tối.

Dữ liệu đang lưu trên trình duyệt (IndexedDB). Chưa có tài khoản, chưa đồng bộ lên server.

Tính năng chung toàn app

Giao diện Có

  • 3 chế độ màu: Sáng, Tối, Theo hệ thống (tự đổi khi máy đổi).
  • 2 phong cách: Vẽ tay (viền nét bút) và Phẳng.
  • 3 kích thước giao diện: Nhỏ, Vừa (mặc định), Lớn. Áp cho canvas, thanh công cụ, Khay chờ, header, modal Cài đặt.

Đa ngôn ngữ Có

  • Tiếng Việt và English, đổi trong Cài đặt, đổi là áp ngay.
  • Lần đầu theo ngôn ngữ trình duyệt, chọn rồi thì nhớ lựa chọn.
  • Số, dung lượng định dạng theo ngôn ngữ (1,5 / 1.5).

Vài chữ trong toolbar Note vẫn tiếng Anh (Bold, Link, Save...).

Chặn zoom trang Có

  • Pinch trackpad hoặc Ctrl + lăn chuột không làm trình duyệt phóng cả trang.
  • Trên Canvas, thao tác đó phóng to / thu nhỏ canvas.

Kiểu bàn phím Có

  • Tự nhận máy Mac hay Windows / Linux, hoặc chọn tay trong Cài đặt.
  • Mac hiện ký hiệu ⌘ ⌥ ⇧, Windows hiện Ctrl Alt Shift ở mọi tooltip và bảng phím.

Board lồng nhau Có

  • Tạo board con bằng tile Board ở thanh công cụ trái (bấm hoặc kéo ra canvas).
  • Board con hiện dạng khối vuông màu + tên + số card bên trong. Màu tự xoay vòng theo bảng 6 màu.
  • Double-click khối màu → vào board đó. Double-click tên → đổi tên.
  • Kéo note / board thả lên 1 board tile → chuyển vào board đó (rơi vào Khay chờ của board đích). Kéo board vào board khác cũng đổi luôn quan hệ cha con.
  • Chặn tạo vòng: không thả được board vào chính nó hoặc board con của nó.
  • Xoá board: hỏi xác nhận, báo số object + board con sẽ mất, xoá cả cây bên trong.
  • Board gốc tên "Home", không đổi tên được.

Khay chờ (Unsort) Có

Panel bên phải chứa object chưa đặt lên canvas. Mỗi board có Khay chờ riêng.

  • Mở bằng tab ở mép phải canvas, đóng bằng nút X hoặc Esc.
  • Object chuyển từ board khác sang luôn vào đầu Khay chờ của board đích.
  • Kéo lên / xuống trong khay để đổi thứ tự (có vạch báo chỗ thả).
  • Kéo từ khay ra canvas để đặt vị trí, hoặc kéo lên board tile để chuyển tiếp sang board khác.
  • Ctrl + Shift + U: đưa object đang chọn trên canvas vào khay.
  • Chọn nhiều trong khay: Ctrl / Shift + bấm, Shift + bấm chọn liên tiếp, Ctrl + A chọn hết trong khay.
  • Xoá, hoàn tác trong khay giống trên canvas.

Lưu và hoàn tác Có

  • Tự lưu mọi thay đổi vào trình duyệt, không cần bấm lưu. Dùng hàng đợi ghi để kéo liên tục không ghi dồn dập.
  • Hoàn tác / làm lại tới 100 bước: tạo, di chuyển, đổi kích thước, xoá, đổi màu, sắp lớp, dán, chuyển board, tách đoạn.
  • Thao tác gộp (VD dán 5 object, tách đoạn) chỉ tính 1 bước hoàn tác.
  • Dữ liệu cũ (từ trước khi đổi cấu trúc) tự chuyển sang dạng mới khi mở canvas.

Note

Loại object chính trên canvas: thẻ chữ có định dạng (rich text), kiểu Milanote.

Tạo và sửa Có

  • Tạo: bấm hoặc kéo tile Note từ thanh trái, hoặc chuột phải vùng trống → "Thêm Note".
  • Vào sửa: double-click (con trỏ đặt đúng chỗ bấm), hoặc chọn rồi bấm Enter (con trỏ ở cuối).
  • Thoát sửa: Esc, Ctrl + Enter, hoặc bấm ra ngoài. Nội dung lưu khi thoát.
  • Note mới chỉ có 1 dòng trống, có chữ gợi ý mờ.
  • Chữ tiêu đề dùng font Fraunces (có chân), thân chữ cỡ nhỏ.

Kiểu chữNút "Text style" → Title (H1), Heading (H2), Subheading (H3), Body, Quote. Hoặc Ctrl + Alt + 1 / 2 / 3.
Đậm, nghiêng, gạch chân, gạch ngang, codeCtrl + B / I / U, Ctrl + Shift + S, Ctrl + E. Đậm và nghiêng có nút trên thanh.

Màu, kích thước Có

  • Màu: chọn note → nút Màu → 6 màu (Đỏ, Cam, Vàng, Xanh lá, Xanh dương, Tím) hoặc Mặc định. Màu hiện ở dải trên đầu note.
  • Tự cao theo chữ: gõ thêm thì note cao lên, rộng / hẹp lại thì tự tính lại.
  • Kéo góc phải dưới để đổi cả rộng lẫn cao. Đã kéo tay thì note giữ chiều cao đó, chữ dài hơn thì mờ dần ở đáy.
  • Rộng mặc định 338px (giống Milanote).

Tách đoạn ra note mới (Card Clipper) Có

  • Rê chuột lên 1 đoạn trong note → hiện icon thẻ nhỏ bên phải đoạn đó.
  • Kéo icon ra canvas → tạo note mới chứa đoạn đó, note gốc mất đoạn đó (cắt).
  • Giữ Alt khi thả → giữ lại đoạn ở note gốc (chép).
  • Note mới lấy màu của note gốc. Hoàn tác 1 lần trả lại như cũ.

An toàn dữ liệu Có

  • Nội dung note được lọc trước khi hiện và khi dán: bỏ script, thuộc tính lạ, link javascript:.
  • Dữ liệu dán từ clipboard bị kiểm từng object, object sai dạng bị bỏ.

Hệ thống phím tắt

  • Modal phím tắt: bấm / hoặc Trợ giúp → Phím tắt. Đóng bằng Esc: ô tìm có chữ thì Esc xoá chữ trước, ô trống mới đóng modal.
  • Chia nhóm bên trái: Thường dùng, Cơ bản, Định dạng chữ, Markdown, Di chuyển, Giao diện, Thu phóng. Bấm nhóm để nhảy tới, cuộn thì nhóm đang xem tự tô.
  • Ô tìm: gõ tên thao tác, tên nhóm hoặc tên phím. Không cần dấu ("xoa" ra "Xoá").
  • Phím hiện đúng theo máy: Mac ⌘ ⌥ ⇧, Windows Ctrl Alt Shift.
  • Phím không chạy khi đang gõ chữ trong ô nhập (trừ Esc để đóng popup).
  • Esc đóng lớp trên cùng trước: popup → panel → bỏ chọn. Popup / hộp thoại đang mở thì phím canvas không chạy ngầm.
  • Không bị ảnh hưởng bởi Caps Lock.

Bảng dưới ghi theo Windows. Trên Mac thay Ctrl bằng ⌘.
