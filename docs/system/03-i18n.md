## Hiện trạng

### Cấu trúc

| File | Việc |
|---|---|
| `index.ts` | Cửa vào duy nhất: `useI18n()` (trong component), `t()` / `formatNumber()` (ngoài React), export lại store + type |
| `locale-store.ts` | Store Zustand `useLocaleStore`, lưu localStorage `bibo-locale`. `applyLangAttr` gắn `<html lang>` |
| `messages.ts` | Nạp 2 file JSON, type `Messages` lấy từ `vi.json`, type `MessageKey` (mọi đường dẫn key) |
| `translate.ts` | Phần thuần không dính React: tra key, chọn số nhiều, chèn biến, định dạng số. Cache `Intl.*` theo ngôn ngữ |
| `locales/vi.json`, `en.json` | Bộ chữ. Mỗi bộ 361 câu. Vùng gốc: `COMMON`, `LOCALE`, `SETTINGS`, `SHORTCUTS`, `CANVAS`, `LANDING` |

Không dùng thư viện ngoài. Chữ ký `t(key, params)` giữ giống `react-i18next` để sau đổi chỉ thay phần dưới (spec `i18n`: đổi khi > 5 ngôn ngữ, tải chữ từ server, hoặc nối dịch vụ dịch).

### Kiểm thiếu key

- `vi.json` là nguồn chuẩn: `Messages = typeof vi`.
- `messages.ts` khai `const en: Messages = enJson` → `en` thiếu key hoặc sai dạng là `tsc` báo tại dòng này.
- Không bắt được: key có ở `en` mà `vi` không có (key thừa), câu `en` còn tiếng Việt. Phần này để bước rà soát (Task 6 spec `i18n`).
- Gõ sai key trong code: `tsc` báo vì `t()` nhận `MessageKey`.

### Dịch 1 key (`translateFor`)

1. Tra key theo ngôn ngữ đang chọn.
2. Không có → tra bản dự phòng `en`.
3. Vẫn không có → trả lại chính chuỗi key (dễ thấy trên UI), bản dev in cảnh báo console.

Chèn biến: `{tên}` trong câu thay bằng tham số. Tham số là số thì tự định dạng theo ngôn ngữ. Biến không truyền thì giữ nguyên `{tên}`.

Số nhiều: key là object có `other` (bắt buộc), `en` thêm `one`. Truyền `count` là số → `Intl.PluralRules` chọn dạng, thiếu dạng đó thì lấy `other`. Tiếng Việt chỉ cần `other`.

Định dạng số: `formatNumber(n)` → vi `1.234`, en `1,234`. Tham số thứ 2 cố định số chữ số thập phân (`formatNumber(1.5, 1)` → vi `1,5`). Cả app còn 0 chỗ gọi `toLocaleString` / `Intl` ngoài `lib/i18n`.

### Trong React và ngoài React

- `useI18n()` trả `{ locale, t, formatNumber }`, đổi ngôn ngữ là render lại. `t` / `formatNumber` bọc `useCallback` vì hay nằm trong deps.
- `t()` / `formatNumber()` export thẳng: đọc ngôn ngữ lúc gọi, không tự đổi khi đổi ngôn ngữ. Chỉ cho chữ tạo 1 lần. Hiện chưa có chỗ nào trong code gọi (engine giữ label undo tiếng Anh, chưa hiện trên UI).
- Hằng số ngoài component (danh sách mục Cài đặt, màu note, nhóm phím) lưu `MessageKey`, dịch lúc render. Mẫu: `SECTIONS` trong `SettingsModal.tsx`, `note-colors.ts`, `display.labelKey` trong bảng phím.

### Chọn ngôn ngữ

- Lần đầu (chưa có `bibo-locale`): `navigator.language` bắt đầu bằng `vi` → `vi`, còn lại → `en`. Kết quả đoán không ghi xuống localStorage; mỗi lần mở lại theo trình duyệt cho tới khi người dùng chọn.
- Người dùng chọn ở Cài đặt → Ngôn ngữ và vùng (`LocalizationSection`, nút Segmented). Bảng dev (`src/dev/DevPanel.tsx`, chỉ dev) cũng đổi được.
- Không có tiền tố URL `/vi`, `/en` (chốt 2026-10-05): link chia sẻ hiện theo ngôn ngữ người xem.
- `App.tsx` gắn `<html lang>` theo store. Tên ngôn ngữ (`LOCALE.*`) luôn viết bằng chính tiếng đó.

### Landing

- `LandingRoot.tsx` dùng chung store, gắn `<html lang>`. 14 file landing dùng `useI18n()`, chữ ở vùng `LANDING`.
- Landing khác origin với app nên không thấy `bibo-locale` của app (`INV-CORE-06`). Landing không có nút chọn ngôn ngữ: luôn theo trình duyệt.
