Object Inspector

Panel bên phải xuất hiện khi chọn 1 object bất kỳ (finding, table, note, source). Đây là nơi bibo thể hiện triết lý provenance.

  • Provenance: mọi object biết mình từ đâu ra, click mở đúng đoạn nguồn.
  • Độ tin cậy: với object AI trích xuất, hiện % confidence.
  • Quan hệ: object này liên kết với object nào (derived from, supports, compares).
  • Contextual action: action đến từ plugin, chỉ hiện action hợp với loại object.
