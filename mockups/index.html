Mockup Preview

bibo — Hình dung dự án

12 trang mockup để hình dung workspace, canvas, plugin store và các flow chính. Click 1 card để mở, dùng Alt+← để quay lại.

01

Landing công khai

Trang giới thiệu dự án cho công chúng. Hero, feature, footer.

 02

App Home / Dashboard

Màn hình đầu sau khi login. Workspace switcher, activity, quick actions.

 03

Workspace Manager

Danh sách workspace, tạo mới, phân quyền, active plugin.

 04

Canvas Workspace

Canvas tương tác với sidebar, board, inspector. Object + connector + provenance.

 05

Plugin Store

Catalog plugin. Filter, search, install per workspace.

 06

Plugin Detail

Chi tiết plugin: permission, object contract, changelog, screenshot.

 07

Notes Browser

Duyệt note, tag, filter, quick create.

 08

Sources Library

Kho nguồn: PDF, ảnh, web clip. Metadata, provenance link.

 09

Command Palette

Ctrl+K overlay. Search, contextual action, recent.

 10

Settings

Workspace + user settings: theme, notification, plugin permission.

 11

Onboarding

Flow đầu tiên: chọn use case, install pack, tạo workspace.

 12

Object Inspector

Panel chi tiết object: provenance, relation, contextual action.
